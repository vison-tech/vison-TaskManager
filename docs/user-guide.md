# TaskManaer-Vison 使用说明

适用版本：0.1.0，2026-11-01 更新。当前安装包面向 Apple Silicon（M 系列芯片）、macOS 14 及以上。

## 1. 安装与第一次启动

1. 解压安装包，把 `TaskManaer-Vison.app` 拖到“应用程序”。应用内置运行环境，普通使用无需安装 Node 或 npm。
2. 双击应用，检查“数据目录”。新用户可使用默认目录；已有任务的用户点击“选择数据目录…”，选择包含 `taskmanager.sqlite` 的原文件夹。
3. 选择使用方式。第一次建议选“浏览器使用”，点击“启动看板”，等待就绪后点击“打开看板”。
4. 日常使用完毕点击“停止”，或退出应用。应用管理自己启动的服务；停止不会删除任务数据。

默认数据目录：`~/Library/Application Support/TaskManager/data`。应用改名后保留该目录名称，以兼容旧配置。

默认端口为 47830；此前开发实例使用 47831。以启动窗口显示的地址为准。如果端口已被占用，先正常停止旧实例，或选择另一个空闲端口。

当前试用包尚无 Apple 开发者签名和公证。若 macOS 阻止打开，确认来源可信后查看“系统设置 → 隐私与安全”是否提供“仍要打开”。不要关闭系统整体安全保护；没有可用选项时保留提示信息用于排查。

## 2. 已有数据如何继续使用

数据目录与应用文件分开。替换应用不会自动搬移任务，也不会把旧目录内容合并进新目录。

如果启动后没有原来的项目，先停止服务，再核对数据目录；不要立即删除或覆盖任何数据库。选择原目录后重新启动。

本次开发曾使用临时目录 `/private/tmp/taskmanager-embed-chQJ2E`。临时目录不宜长期保存任务。若你仍使用它，请停止所有访问该目录的服务，把整个文件夹复制到固定位置，再在启动窗口选择新位置；确认任务和附件正常后保留旧目录作为备份。

## 3. 项目与任务

- 点击侧栏“新建项目”，填写名称和可选编号前缀。项目设置中可补充工作区路径、标签和 README。
- 点击“创建”新增任务，设置描述、状态、优先级、负责人、标签和日期。
- 看板支持拖动调整顺序或状态；列表适合集中查看和编辑字段。搜索与状态筛选用于缩小范围。
- 打开任务详情可编辑字段、评论、上传附件、管理任务关系和关联 Agent 会话。
- 仪表盘查看任务分布、趋势和完成度；时间轴查看有日期的任务、依赖关系并调整日期。
- 归档用于移出活跃列表，可通过“包含归档”查找并恢复。永久删除前先核对对象。

重复任务需要设置截止日期。使用任务的“完成”操作生成下一期；仅把状态改成“已完成”不等于执行周期完成操作。

偏好设置支持语言和浅色／深色主题。Codex 嵌入模式还可跟随宿主主题；项目视图、搜索、筛选等偏好按项目保存。

## 4. 开发工作区、分支与 worktree

1. 在项目设置中填写本机仓库的绝对路径并保存。
2. 新建或编辑任务，在“开发工作区”点击“刷新工作区”。
3. 选择项目默认目录、Git 分支或 worktree，然后保存任务。
4. 在任务详情核对已保存的开发上下文。

扫描是只读操作。选择分支只记录上下文，不会自动 checkout；使用项目默认目录或分支上下文时，Agent 在项目目录中运行，实际检出的分支以本地仓库为准。

选择 worktree 时，AI 对话会检查该目录确实是所属项目登记的 worktree，再用它作为运行目录。目录已删除、不可访问或不属于项目时会报错。重新扫描并选择有效项即可。

## 5. Codex 输入框联动

需已安装 Codex 桌面应用，且通过启动器“Codex 内使用”模式启动。普通浏览器中的看板不具备当前 Codex 会话桥接。

1. 在 Codex 中打开目标本地会话，再打开任务面板。
2. 打开任务详情，在“Agent 会话”点击“关联当前 Codex 会话”。
3. 点击“查看任务草稿”，检查任务标题、描述和开发上下文。
4. 确认 Codex 输入框为空，点击“填入当前对话草稿”。
5. 填入成功后面板关闭，回到 Codex 检查文本，再由你点击发送。

已有草稿时会拒绝覆盖；会话变化或无法确认输入框时会报错。可先处理已有草稿，刷新当前会话并重试，或用“复制草稿”手动粘贴。该操作不会自动发送消息。

此适配依赖 Codex 界面版本。受控测试已通过，真实宿主填入仍需实际验收；界面提示不支持时，不应反复尝试覆盖输入框。

## 6. 任务内 AI 对话

任务内 AI 对话通过独立本地 Agent 进程运行，与 Codex 输入框草稿是两个入口。应用保存任务内对话历史，并把有限历史作为下一轮上下文；不会自动续接桌面里当前会话的完整历史。

### 启用本地 Claude

需要本机已安装并完成登录的 Claude CLI。当前桌面启动窗口还没有 Agent 配置表单；双击应用不会自动启用终端里的临时配置。可用下面方式启动包内服务，免装 Node。

先停止已有 TaskManaer-Vison 服务。打开终端，把应用和数据路径替换成你的实际路径后执行：

```sh
TASKMANAGER_AGENT_COMMANDS="$(command -v claude)" \
TASKMANAGER_AGENT_PERMISSION_MODES=read \
"/Applications/TaskManaer-Vison.app/Contents/Resources/node" \
"/Applications/TaskManaer-Vison.app/Contents/Resources/app/apps/desktop/index.mjs" \
--mode web \
--data-dir "$HOME/Library/Application Support/TaskManager/data" \
--port 47831
```

执行前可运行 `command -v claude`，应输出可执行文件路径；没有输出则先安装并登录 Claude CLI。已有任务必须使用原数据目录。命令运行期间保留终端，打开终端输出的看板地址；结束时按 Ctrl+C。

要同时启用 Codex 面板，可将 `--mode web` 改为 `--mode embed`。这会按启动器配置连接或启动 Codex。

默认只读模式向 Claude 提供 Read、Grep、Glob 工具。若明确需要修改文件，可把权限配置改为 `read,write`，再在对话设置中选择 write。托管适配器不支持 full、额外命令参数或外部技能执行。只读工具限制不等同于操作系统文件隔离。

模型默认使用 Claude 本地配置。需要在界面选模型时，由启动环境设置 `TASKMANAGER_AGENT_MODELS`，值为账号实际可用的模型 ID，多个以逗号分隔。不要把不确定的模型名称当作可用能力。

### 发送、附件与继续对话

1. 打开任务详情中的 AI 对话，选择配置好的 Agent。
2. 输入请求。应用会附带任务描述、状态、标签及开发上下文。
3. 如需附件正文，勾选任务附件，或通过 `@` 候选选择附件。
4. 点击发送，查看输出；运行中可停止，完成后发送下一条继续讨论。关闭后重新打开可读取已保存历史。

附件目前支持 UTF-8 文本：最多10个，每个64 KiB，总计256 KiB。图片、PDF及二进制内容解析尚不支持；越权、过大或不可解码的文件会报错，不会被静默当作已读取。

每轮最多使用最近40条用户／助手消息，单条最多6000字符，总计24000字符。长历史可能被截短；关键要求请在当前请求中明确重述。“压缩历史”目前是确定性折叠，不是模型生成的语义总结。

AI 执行结束不自动把任务标记为完成，请检查结果后自行更新任务状态。真实登录、配额和模型回复需通过你实际发送的请求确认。

本机开发检查发现 Codex CLI 缺少平台依赖，因此当前优先支持 Claude。桌面 Codex 草稿联动不依赖该 CLI。

## 7. 更新、备份与恢复

更新：先停止旧服务并退出应用，备份数据，然后替换 `.app`。重新启动时选择原数据目录。不要同时启动桌面入口和手动服务占用同一端口。

备份：先停止所有访问该数据目录的实例，把整个数据目录复制到独立备份位置。应包含数据库和附件目录，不要只复制 `taskmanager.sqlite`。可另外保存 `~/Library/Application Support/TaskManager/launcher.json`，用于恢复启动配置。

恢复：停止服务，将备份复制到一个新的固定目录，在启动窗口选择该目录，启动后检查项目、任务、评论和附件。验证完成前保留旧目录。

卸载：删除 `.app` 即移除程序；数据和配置仍保留在应用外。若需要清理数据，先自行确认备份。

## 8. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 看板打不开 | 确认启动状态就绪，使用窗口显示的端口；检查“查看日志” |
| 地址仍显示旧界面 | 刷新网页；确认运行的是新版包，而不是旧服务 |
| 原来的任务不见了 | 停止服务，核对所选数据目录是否为原目录 |
| 端口被占用 | 正常停止旧实例，或换一个空闲端口 |
| 工作区无法扫描 | 检查绝对路径、目录权限和 Git 安装；非仓库目录不能列出分支 |
| 草稿按钮不可用 | 通过Codex嵌入模式打开，进入本地会话并刷新；不兼容时复制粘贴 |
| 输入框已有草稿 | 先自行保存、发送或清空原草稿，避免覆盖 |
| AI 对话不可用 | 检查是否按第6节显式配置Agent并重启服务 |
| AI 报认证／额度／模型错误 | 检查Claude自身登录、账号配额和所选模型；安装包不提供模型额度 |
| 附件无法加入对话 | 检查是否为UTF-8文本，以及单文件和总大小限制 |

## 9. 当前支持边界

已完成构建、服务端与组件回归、包搬移和数据库持久化检查。真实 Codex 操作、模型回复及干净机器安装仍需实际验收。

尚未包含云同步、Claude原生界面嵌入、Jira双向同步、自动更新、托盘和正式签名／公证。数据当前保存在本机，任务描述与所选附件会在发送AI请求时交给所配置的Agent及其模型服务处理。
